# Word Guess Game 🎯

A simple Python word guessing game where you try to guess the hidden word one letter at a time before running out of attempts.

## How to Play
1. Run the program using Python.
2. The game will randomly choose a word from a list.
3. You’ll see blanks (_) for each letter in the word.
4. Guess one letter at a time:
   - If correct, the letter appears in its position.
   - If wrong, you lose one attempt.
5. You have 10 attempts to guess the word correctly.

## Example Output
Current word: _ _ _ _ _
Guess a letter: i
Great guess!
Guess a letter: o
Wrong guess! Attempts left: 9

## Technologies Used
- Python 3
- random module

## How to Run
1. Clone this repository:
   git clone https://github.com/CHAITHAN16/Word_Guess_Game.git
